# Team Task Manager

A full-stack Team Task Manager web app built using MERN stack.

## Features

- User Signup
- User Login
- Add Projects
- View Projects
- Add Tasks
- Complete Tasks
- Delete Tasks
- MongoDB Database
- Vercel Deployment

## Tech Stack

Frontend:
- React
- Axios
- CSS

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
